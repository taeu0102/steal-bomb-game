# 데스 카운트 — 실제 플레이 규칙 v2

2026-09-07 사용자 설명 반영. 초기 GDD의 단독 폭탄 즉시 종료 및 크래시 숫자의 새 폭탄 대체 규칙을 아래 내용으로 변경한다.

1. 15명이 방에 입장하고 방장이 시작한다. 연습은 본인과 봇 14명으로 진행한다.
2. 서버가 비밀 폭탄을 1~15 중 하나로 정하고, 무작위 3명에게만 참인 단편 힌트를 준다.
3. 버튼을 눌러 숫자를 올린다. 서버가 숫자마다 입력자를 기록한다. 단독으로 폭탄 숫자를 눌러도 이때는 종료하거나 폭탄을 공개하지 않는다.
4. 최초 입력부터 200ms 이하에 다른 사람이 누르면 크래시로 끝나고, 창 안의 모든 입력자를 충돌 벌칙자로 정한다.
5. 충돌 결과 후 1.8초의 정적을 두고 원래 폭탄 숫자를 공개한다. 그 숫자를 이미 눌렀던 사람이 있다면 폭탄 벌칙자로 추가한다.
6. 폭탄 숫자까지 도달하지 않았다면 추가 벌칙자는 없다. 충돌과 폭탄에 모두 해당해도 한 번만 벌칙자로 계산한다.
7. 충돌 없이 15까지 가면 카운트를 종료하고 폭탄 벌칙만 공개한다. 16으로 진행하지 않는다.
8. 최종 벌칙이 없는 사람에게 1승. 매 판 전원 복귀, 먼저 2승 공동 우승 가능, 최대 3판 후 최고 승수 우승. 모두 0승이면 무승부다.

예: 폭탄 3을 A가 눌렀고, 7에서 B·C가 함께 누른 경우 → B·C 충돌 벌칙 → 폭탄 3 공개 → A 추가 벌칙. 폭탄이 10이라면 7에서 끝났으므로 B·C만 벌칙이다.

공개 전에는 폭탄 번호, 추가 벌칙자, 숫자별 기록, 최종 승수·승자를 서버 응답에서도 감춘다. 입력 판정은 원자적 SQL과 서버 DB 시각을 사용하며, 단독 입력 쿨타임은 실제 확정 쓰기 이후 500~1500ms다.
