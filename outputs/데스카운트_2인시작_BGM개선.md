# 데스 카운트 — 2~15인 플레이와 사운드 개선

반영일: 2026-09-08

## 참가 인원

- 일반 방은 최소 2명, 최대 15명으로 시작할 수 있습니다. 봇을 넣지 않고 실제 참가자 수로 진행합니다.
- 방장에게 “현재 인원으로 게임 시작” 버튼을 표시합니다. 1명일 때만 참가자를 더 기다립니다.
- 개인전은 2명부터, 2팀전은 각 팀 1명부터 시작할 수 있습니다. 3팀전은 각 팀 최소 1명이라는 기존 규칙을 유지합니다.
- 새 팀전의 화면 기본 선택은 2팀입니다. 기존 방의 팀 설정은 유지합니다.
- 혼자 연습은 기존대로 사람 1명과 봇 14명입니다.
- 힌트는 최대 3명에게 제공하며 2인 플레이에서는 두 사람에게 제공합니다. 공통 카운트와 폭탄 숫자 범위는 기존 1~15를 유지합니다.

## 오리지널 BGM과 효과음

외부 음원을 가져오는 대신 WebAudio로 직접 작곡·합성하는 94 BPM의 4마디 BGM을 적용했습니다. 베이스 F#–D–E–G, 얇은 패드, 킥·스네어·하이햇으로 구성합니다.

- 낮은 카운트: 느슨한 저음과 패드로 긴장감 형성.
- 중간 카운트: 베이스·하이햇 밀도 증가.
- 높은 카운트: 고음 스텝 추가로 압박감 강화.
- 버튼 입력: 짧고 명확한 클릭 톤.
- 단독 성공: 두 겹의 보상 효과음과 음악 볼륨 감소.
- 충돌·폭탄: 음악을 멈추고 저음 충격·노이즈 효과음 강조.
- 결과·숨긴 탭·연결 끊김·음소거·페이지 종료 시 음악과 타이머를 적절히 정리합니다.

실제 폭탄 위치를 음악에 전달하지 않고 공개된 카운트만 사용하므로 소리로 비밀 숫자가 누설되지 않습니다. 사용자 조작 후 브라우저가 허용하는 시점부터 재생합니다. 압축 리미터로 음량 피크를 제한합니다.

## 검증

규칙 테스트 29개, 오디오 장면 전환·중복 루프·음소거·종료 정리 테스트 1개를 통과했습니다. 2인 개인전·팀전 HTTP 시작과 봇 14명 연습 구성도 확인했습니다. 오디오 자동 검증은 재생 구조와 수명주기 검증이며 기기별 청감 평가를 대체하지 않습니다.
