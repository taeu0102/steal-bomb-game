# 폭탄 없는 라운드

개인전·팀전 모두 매 라운드 20% 확률로 폭탄 없이 진행됩니다. 나머지 80%는 기존처럼 1~15 중 폭탄 숫자를 정합니다.

- 무작위 3명만 “이번 라운드에는 폭탄이 없다.” 힌트를 받습니다.
- 다른 참가자는 라운드 종료 시 공개되기 전까지 폭탄 유무를 알 수 없습니다.
- 여러 명이 동시에 누르면 기존과 동일하게 충돌 종료·벌칙을 적용합니다. 충돌 입력 보상은 0점이며 누적 점수 초기화는 없습니다.
- 충돌 없이 15까지 도달하면 종료하고 모든 참가자가 획득 점수를 유지합니다.
- 종료 화면에는 숫자 0 대신 “폭탄 없는 라운드 / 없음”을 표시합니다.
- 숫자별 보상, 쿨타임, 팀전 연속 제한과 팀 구성 규칙은 유지합니다.

기존 JSON 상태에서 폭탄 숫자 0을 '폭탄 없음'으로 사용하며 새 DB 테이블은 생성하지 않습니다.
