# 폭탄 즉시 종료 규칙

이 규칙은 이전 문서의 '폭탄을 단독으로 눌러도 계속 진행' 규칙을 대체합니다.

- 공통 숫자가 폭탄 숫자에 도달하면 라운드를 즉시 종료합니다.
- 200ms 동시 입력 창이 끝난 뒤 서버가 확정합니다. 단독 폭탄은 BOMB, 여러 명 동시 입력은 CRASH로 판정합니다.
- 단독 폭탄 종료 시 숫자와 벌칙자를 바로 공개하고, 담당자의 이전 라운드를 포함한 누적 점수를 0점으로 표시합니다.
- 종료 뒤 다음 숫자 입력은 서버에서 거절됩니다. 방장은 기존 종료 대기 시간 뒤 다음 라운드를 시작할 수 있습니다.
- 폭탄 숫자에서 충돌했다면 충돌자 모두 폭탄 초기화 대상입니다. 충돌의 기존 지연 공개 연출은 유지합니다.
- 개인전과 2팀·3팀 팀전에 동일하게 적용됩니다.

검증: 규칙 회귀 테스트와 `tests/bomb-http.test.mjs`의 15명 순차 입력으로 폭탄 종료·즉시 공개·0점·추가 입력 거절을 확인합니다.
