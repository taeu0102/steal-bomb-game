# Portfolio City

10개 종목으로 도시를 키우는 투자 시뮬레이터 프로토타입입니다. 기존 축구 포메이션형 ETF 보드의 장점은 유지하되, 사용자가 직접 종목을 담고 다음날 결과를 비교하는 도시 성장 게임 콘셉트로 확장했습니다.

## 핵심 규칙

- 스쿼드는 정확히 10개 종목으로 구성합니다.
- 안정형 예금 또는 국채는 최소 3개가 필요합니다.
- 고수익형은 최소 1개가 필요합니다.
- 안정 투자형은 예금·국채를 포함해 최대 5개까지만 허용합니다.
- 시드머니는 10,000만원이며 각 종목의 투자금이 건물 규모와 수익 기여도로 표시됩니다.

## 이번 고도화 내용

- 종목 검색, 필터, 담기/제거 흐름을 추가했습니다.
- 10개 스쿼드 규칙을 실시간으로 검증하는 패널을 추가했습니다.
- 시청을 중앙에 고정하고 선택한 10개 종목을 도시 부지에 배치했습니다.
- 예금, 국채, 반도체, HBM, 제조업, 중공업, 조선업, 에너지, ETF 건물의 일러스트 실루엣을 구분했습니다.
- 최대 8인까지 비교할 수 있는 샘플 멀티플레이 랭킹을 추가했습니다.
- 종목 클릭 시 뉴스 패널과 가격 흐름 패널이 함께 갱신됩니다.
- Web Audio API 기반의 짧은 효과음을 추가했습니다. 별도 음원 파일은 사용하지 않습니다.
- 도시 맵을 좌측의 큰 게임 화면으로 확장하고, 규칙·검색·뉴스·랭킹·리포트 패널은 우측 운영 패널에 모았습니다.
- 10개 건물 슬롯을 격자 대신 비대칭 위치로 배치해 SLG 게임 화면처럼 보이도록 조정했습니다.
- 도시 구현 영역을 중형 맵 크기로 다시 압축해 빈 공간과 과도한 캔버스 느낌을 줄였습니다.
- 장 시작, 장 중, 장 마감 시간대를 추가하고 아침, 정오, 노을 배경 톤이 메인 맵에 반영되도록 했습니다.
- 도로, 언덕, 농지, 구름, 조명, 그림자 레이어를 추가해 원본 SVG 기반의 SLG풍 지형 표현을 강화했습니다.
- 게임 보드와 우측 커맨드 패널이 뷰포트 높이를 채우도록 재구성해 하단 빈 공간과 긴 페이지 스크롤을 줄였습니다.

## API 연결 방식

정적 GitHub Pages에서는 API 키를 안전하게 숨길 수 없습니다. 실제 종목 검색이나 뉴스 API를 붙일 때는 서버리스 프록시를 만들고 `assets/config.js`에 프록시 주소만 넣는 방식이 안전합니다.

```js
window.PORTFOLIO_CITY_CONFIG = {
  stockSearchEndpoint: "https://example.com/api/stocks",
  newsEndpoint: "https://example.com/api/news",
};
```

예상 요청 형식:

- 종목 검색: `GET /api/stocks?q=삼성전자`
- 뉴스 조회: `GET /api/news?ticker=005930&name=삼성전자`

응답은 배열 또는 `{ items: [] }`, `{ results: [] }`, `{ data: [] }` 형태를 지원합니다.
