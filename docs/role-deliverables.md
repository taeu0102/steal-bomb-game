# 흥부와 놀부 인터랙티브 동화: 역할별 책임과 산출물

## 문서 목적

이 문서는 부모와 아이가 함께 읽고 선택하는 인터랙티브 동화 게임을 제작하기 위해 필요한 9개 역할의 책임, 산출물, 인수 조건을 정의한다. 첫 에피소드는 한국 고전 `흥부와 놀부`이며, 이후 다른 전래동화를 동일한 플레이어에서 데이터와 에셋 추가만으로 확장하는 것을 전제로 한다.

## 제품 기준

- 대상: 만 5~9세 아동과 보호자
- 세션 길이: 8~12분, 기준 플레이 시간 약 10분
- 핵심 흐름: `장면 감상 → 선택 → 정답이면 진행 / 비권장 선택이면 즉시 새드 엔딩 → 재도전`
- 상호작용: 클릭·터치 중심, 한 화면에 최대 3개 선택지
- 선택 실패: `새드 엔딩 · 실패`와 정확한 교훈을 표시하고 `다시 선택하기`만 제공
- 접근성: 큰 글자와 버튼, 자막, 음소거, 키보드 조작, 의미 있는 소리의 자막 제공
- 저장: 장면 진입 및 선택 직후 자동 저장, 마지막 체크포인트부터 이어보기
- 확장성: 에피소드 매니페스트와 장면 데이터로 콘텐츠를 등록하고 공통 장면 플레이어가 실행

## 역할 간 작업 흐름

1. 기획이 제품 목표, 범위, 장면 계약, 완료 조건을 고정한다.
2. 내러티브가 원작 각색표와 전체 장면·선택 대본을 작성한다.
3. 영상 디렉터, 아트, 사운드, 뮤직, UX가 같은 장면 ID를 기준으로 제작 사양을 만든다.
4. 프론트엔드가 장면 데이터와 에셋을 공통 플레이어에 연결한다.
5. QA가 기능, 분기, 아동 안전, 모바일, 접근성을 함께 검증한다.

모든 산출물은 `HB00_TITLE`처럼 변경되지 않는 장면 ID를 공통 키로 사용한다.

## 1. 기획

### 책임

- 목표 연령, 공동 읽기 방식, 플레이 시간, 핵심 교훈을 정의한다.
- 자동 진행과 선택 구간의 비율, 분기 범위, 합류 원칙을 결정한다.
- 필수 기능과 후속 기능을 분리하고 출시 범위를 통제한다.
- 각 장면의 ID, 목적, 예상 시간, 체크포인트, 다음 장면을 관리한다.
- 에피소드 데이터 계약과 공통 플레이어 요구사항을 정의한다.
- 각 역할의 산출물을 하나의 출시 기준으로 통합한다.

### 산출물

- 미니 GDD
- 전체 사용자 흐름 및 장면 그래프
- 장면별 시간 예산
- 선택·피드백 매트릭스
- 에피소드 데이터 필드 정의서
- 기능 우선순위와 출시 백로그
- 역할별 인수 조건 및 최종 출시 체크리스트

### 주요 결정 사항

- 정답 선택은 중심 줄거리로 이어지고 비권장 선택은 개별 실패 결말 뒤 같은 질문으로 복귀한다.
- 선택 화면에서는 자동 진행을 멈추고 시간 제한을 두지 않는다.
- 비권장 선택도 아이의 감정이나 의도를 먼저 인정한다.
- 위험 행동은 선택할 수 있더라도 실제 행동 애니메이션으로 재현하지 않는다.
- 선택 결과는 점수보다 `마음 씨앗`과 가족 대화 소재로 되돌려 준다.
- 진행 상태는 장면 중간 프레임이 아닌 안정적인 장면 시작점에 복원한다.

### 인수 조건

- 모든 평가 장면에 정답 1개와 실패 선택별 결과·교훈이 있다.
- 실패 결말에는 무제한 재도전 경로가 있고 필수 시간 제한이 없다.
- 전체 기준 재생 시간이 8~12분 안에 든다.
- 에셋이 누락되어도 정적 화면과 자막으로 진행할 수 있다.
- 새 에피소드가 공통 UI 코드를 수정하지 않고 등록될 수 있다.

## 2. 내러티브

### 책임

- 원작의 핵심 사건과 교훈을 보존하면서 폭력·공포·모욕을 연령에 맞게 완화한다.
- 장면별 내레이션, 대사, 자막 분절, 선택 질문, 결과 문구를 작성한다.
- 흥부와 놀부를 고정된 선인·악인이 아니라 행동하고 변화하는 인물로 구성한다.
- 친절뿐 아니라 공평함, 경계 세우기, 책임 있는 사과와 복구를 함께 다룬다.
- 보호자에게 원작 대비 변경점을 투명하게 알린다.

### 산출물

- 원작 사건·각색 대응표
- 13장면 비트 시트
- 장면별 내레이션·대사·자막 원고
- 선택지·즉시 반응·피드백·합류 행동표
- 등장인물 감정선
- 교훈 태그와 엔딩 가족 대화 질문
- 아동 안전 언어 가이드 및 금지 표현 목록
- 음성 녹음용 최종 대본

### 문체 기준

- 한 문장에는 한 가지 의미만 담는다.
- 한 자막 카드는 최대 2줄을 권장한다.
- 사람의 성격보다 행동과 결과를 설명한다.
- `착한 아이`, `나쁜 아이`, `벌받아 마땅하다`와 같은 판정 표현을 쓰지 않는다.
- `가진 것을 모두 내준다`가 아니라 `서로의 필요를 살피고 공평하게 나눈다`고 표현한다.
- 용서는 강요하지 않고 사과, 반환, 약속, 행동 변화를 함께 제시한다.

### 피드백 작성 공식

1. 선택한 감정이나 의도를 인정한다.
2. 행동이 자신이나 상대에게 미칠 영향을 설명한다.
3. 더 안전하거나 다정한 행동을 하나 제안한다.
4. 실패 결말에서는 같은 질문으로 돌아가 다시 선택하게 한다.

예시:

> 빨리 돕고 싶은 마음이 들었군요. 하지만 갑자기 잡으면 제비가 더 놀랄 수 있어요. 먼저 조용히 살펴봐요.

### 인수 조건

- 모든 비권장 선택에 행동의 결과와 정확한 교훈을 담은 독립 새드 엔딩이 있다.
- 음성이 없어도 자막만으로 사건과 교훈을 이해할 수 있다.
- 원작에서 변경한 폭력 장면이 문서에 모두 기록되어 있다.
- 실패 선택은 본 줄거리로 합류하지 않고 같은 질문에서 재도전한다.
- 엔딩 교훈이 특정 인물을 조롱하거나 아이를 평가하지 않는다.

## 3. 영상 디렉터

### 책임

- 정적인 웹 화면도 영상처럼 느껴지도록 숏, 카메라 이동, 장면 템포를 설계한다.
- 세로형 모바일과 가로형 화면에서 모두 중요한 인물과 자막이 가려지지 않게 한다.
- 선택 직전과 결과 직후의 시선 흐름을 통제한다.
- 놀부네 박 장면을 위협적 재난이 아니라 가볍고 정리 가능한 혼란으로 연출한다.
- 저사양 기기와 모션 감소 설정을 고려한 대체 연출을 정한다.

### 산출물

- 장면별 스토리보드와 애니매틱
- 숏 리스트 및 카메라 큐시트
- 장면 전환 목록
- 캐릭터·자막·선택 UI 세이프 영역
- 애니메이션 시작·종료 상태표
- `prefers-reduced-motion`용 정적 대체안
- 에셋별 화면 비율 및 해상도 요구사항

### 인수 조건

- 모든 장면이 장면 ID와 타임코드를 가진다.
- 선택 UI가 등장할 때 중요 애니메이션과 대사가 끝난 상태다.
- 위험한 행동은 실행 직전 멈춤이나 표정 변화로만 표현한다.
- 장면 전환이 광과민성 위험을 만들 정도로 번쩍이지 않는다.

## 4. 아트

### 책임

- 한국 전래동화의 정서를 살리되 현대 아동에게 친근한 시각 언어를 만든다.
- 흥부와 놀부를 외모로 선악 구분하지 않고 표정과 행동으로 감정을 전달한다.
- 공포감을 줄 수 있는 상처, 괴물, 파괴 이미지를 배제한다.
- 공통 플레이어에 맞는 캐릭터, 배경, 소품, 상태 에셋을 제작한다.
- 향후 에피소드가 같은 UI 안에서 조화롭게 보이도록 공통 아트 규칙을 만든다.

### 산출물

- 아트 바이블과 색상 팔레트
- 흥부, 놀부, 가족, 제비 캐릭터 시트
- 표정·포즈·입 모양 상태표
- 13장면 배경 및 전경 레이어
- 박, 씨앗, 농기구, 바구니 등 소품 세트
- 썸네일, 에피소드 표지, 마음 씨앗 아이콘
- 에셋 ID, 파일명, 크기, 사용 장면을 기록한 매니페스트

### 인수 조건

- 텍스트 없이도 핵심 감정을 구분할 수 있다.
- 320px 너비에서도 중요 대상이 식별된다.
- 선택 가능한 물체는 배경보다 충분히 구별된다.
- 모든 정보성 이미지에 대체 텍스트 초안이 있다.

## 5. 사운드

### 책임

- 내레이션과 인물 대사를 명확하고 안정적인 음량으로 제작한다.
- 효과음이 이야기를 돕되 아이를 놀라게 하지 않도록 한다.
- 음소거 상태에서도 필요한 정보가 소리 자막으로 전달되게 한다.
- 음성 파일이 늦거나 실패해도 자막 진행이 멈추지 않도록 길이 정보를 제공한다.

### 산출물

- 녹음용 VO 대본과 발음 가이드
- 내레이션·대사 음성 파일
- 장면별 SFX 큐시트
- 소리 자막 문구
- 음량, 페이드, 동시 재생 우선순위 기준
- 오디오 에셋 매니페스트

### 인수 조건

- 음성과 배경음이 겹칠 때 음성이 명확히 들린다.
- 갑작스러운 충격음, 큰 깨짐 소리, 비명, 위협적인 저음을 사용하지 않는다.
- 모든 의미 있는 효과음에 자막을 표시할 수 있다.
- 음소거 토글이 즉시 반영되고 다음 방문에도 설정이 유지된다.

## 6. 뮤직

### 책임

- 마을, 제비, 성장, 박, 반성, 화해의 정서 흐름을 음악으로 연결한다.
- 선택을 기다리는 동안 피로하지 않은 짧은 루프를 만든다.
- 한국적 악기색을 활용하되 인물이나 문화를 희화화하지 않는다.
- 놀부의 음악도 공포·악당 테마보다 성급함과 어긋난 마음을 표현한다.

### 산출물

- 음악 테마 및 모티프 정의서
- 장면별 음악 매핑표
- 루프 시작·종료 지점
- 선택 진입 시 덕킹과 장면 전환 페이드 사양
- 무음·저용량 대체 버전
- 음악 에셋 매니페스트

### 인수 조건

- 각 루프의 연결 지점에서 클릭음이나 끊김이 없다.
- 선택 화면에서 음악이 피드백 음성을 가리지 않는다.
- 장면 전환 시 음악 변화가 대사보다 먼저 감정을 강요하지 않는다.

## 7. UX

### 책임

- 보호자와 아이가 한 화면을 함께 보며 쉽게 조작할 수 있는 흐름을 설계한다.
- 큰 버튼, 쉬운 문구, 명확한 진행 상태, 실수 복구를 제공한다.
- 자막, 음소거, 일시정지, 이어보기, 다시 선택하기의 위치와 동작을 정의한다.
- 터치, 마우스, 키보드, 화면 읽기 프로그램을 함께 고려한다.

### 산출물

- 에피소드 선택부터 엔딩까지의 사용자 흐름
- 모바일·태블릿·데스크톱 와이어프레임
- 선택 카드와 정답 피드백·실패 결말 패턴
- 자막·음소거·일시정지·이어보기 사양
- 로딩, 오디오 실패, 저장 실패, 에셋 누락 상태 디자인
- 접근성 주석이 포함된 프로토타입

### 권장 수치

- 최소 터치 영역: 56×56 CSS px
- 한 화면 선택지: 최대 3개
- 선택 문구: 22자 이하 권장
- 본문·자막: `clamp(20px, 4.8vw, 32px)` 권장
- 선택지 간 여백: 최소 12px
- 색상 외에도 아이콘, 문구, 테두리로 상태 표시

### 인수 조건

- 선택에 시간 제한이 없다.
- 터치 한 번으로 음소거와 자막을 바꿀 수 있다.
- 키보드만으로 모든 선택과 엔딩까지 진행할 수 있다.
- 이어보기 시 사용자가 어디서 재개되는지 알 수 있다.

## 8. 프론트엔드

### 책임

- 데이터 기반 장면 플레이어와 에피소드 로더를 구현한다.
- 장면 재생, 선택, 피드백, 합류, 저장·복원을 상태 머신으로 관리한다.
- 반응형 UI, 오디오, 자막, 에셋 선로딩, 오류 대체 동작을 제공한다.
- Vercel 정적 또는 프레임워크 배포 구조에 맞춰 빌드한다.
- 에피소드 데이터의 참조 무결성을 빌드 단계에서 검증한다.

### 산출물

- 에피소드 목록·매니페스트 로더
- 장면 플레이어와 상태 머신
- 내레이션·자막 동기화 모듈
- 선택·피드백·다시 생각하기 컴포넌트
- 로컬 저장 및 버전 마이그레이션
- 이미지·오디오 선로딩과 실패 대체 UI
- 에피소드 JSON 스키마 및 검증 도구
- 반응형 스타일과 접근성 구현
- Vercel 빌드·배포 설정

### 인수 조건

- 새 에피소드가 플레이어 코드 수정 없이 목록과 장면에 나타난다.
- 새로고침 후 마지막 체크포인트에서 복원된다.
- 음성 파일 실패 시 자막과 장면 진행은 유지된다.
- 존재하지 않는 장면·에셋 참조는 빌드 또는 개발 환경에서 명확히 보고된다.
- 모바일에서 가로 스크롤과 선택 버튼 겹침이 없다.

### 산출물

- 장면·선택별 테스트 케이스
- 분기 및 합류 경로 매트릭스
- 지원 화면·브라우저·입력 장치 매트릭스

- 오디오·자막·음소거 동기화 테스트
- 아동 안전 및 언어 검수표
- 접근성 점검표
- 성능·에셋 누락·느린 네트워크 테스트 결과
- 출시 승인 및 회귀 테스트 보고서

### 필수 테스트 항목

- 13개 장면이 순서대로 완료되는가
- 모든 선택에서 피드백 후 올바른 장면으로 합류하는가
- 비권장 선택의 위험 행동이 화면에서 실제 재현되지 않는가
- 선택 화면에서 자동 진행이 멈추는가
- 자막과 음소거 설정이 저장되는가
- 장면 진입 및 선택 직후 진행 상태가 저장되는가
- 320px 너비와 태블릿·데스크톱에서 조작 가능한가
- 키보드 포커스가 논리적인 순서로 이동하는가
- 에셋 하나를 의도적으로 누락해도 엔딩까지 진행되는가

## 전체 완료 정의

- 첫 진입부터 엔딩까지 치명적 오류 없이 완료할 수 있다.
- 전체 기준 시간이 8~12분이다.
- 모든 장면에서 자막과 음소거를 사용할 수 있다.

- 원작의 핵심 사건을 유지하면서 폭력·공포 완화 기준을 충족한다.
- 새 에피소드를 데이터와 에셋 등록만으로 추가할 수 있다.
